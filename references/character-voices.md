# 角色对话风格指南 🎭

## 核心原则

### 一致性
- 每个角色的说话方式要保持一致
- 用词、语气、口头禅要固定
- 让孩子一听就知道是谁在说话

### 儿童化
- 句子短，不要太长太复杂
- 用孩子听得懂的词
- 可以有适当的重复，帮助记忆

## 擎天柱 (Optimus Prime)

### 角色定位
- 智慧的领袖
- 负责任的大哥哥/老师
- 温和但有力量

### 语言特点
- 稳重、从容、不着急
- 经常用"朋友们"、"让我们..."
- 会讲一些简单但有道理的话
- 总是鼓励大家

### 常用开场白
- "汽车人们，今天我们有一个重要的任务..."
- "朋友们，让我们一起来看看..."
- "别担心，我们一步一步来..."

### 讲解知识时
- "你看，这个道理其实很简单..."
- "让我给你举个例子..."
- "记住，关键是..."

### 鼓励时
- "太棒了！你学得真快！"
- "别担心，我们再试一次！"
- "你做得很好！"

### 对话示例
```
擎天柱：汽车人们，今天我们要学习一个有趣的知识！

大黄蜂：是什么是什么？我已经等不及了！

擎天柱：别着急，大黄蜂。今天我们要了解——什么是重力。

大黄蜂：重力？那是什么？听起来很难...

擎天柱：其实一点都不难！你看，当你把玩具丢出去，它会掉到地上，这就是重力在起作用。

大黄蜂：哦！原来是这样！我明白了！

擎天柱：太棒了，大黄蜂！你理解得真快！
```

## 大黄蜂 (Bumblebee)

### 角色定位
- 活泼的小兄弟
- 好奇心强，什么都想试试
- 有时会犯小错误，但会积极改正

### 语言特点
- 语速快，充满活力
- 喜欢用感叹词："哇！"、"太棒了！"、"哦！"
- 经常提问："为什么？"、"是什么？"、"真的吗？"
- 会犯可爱的小错误

### 常用开场白
- "哇！那是什么？"
- "我也要去！我也要去！"
- "听起来好有趣！"

### 提问时
- "为什么会这样呢？"
- "能给我举个例子吗？"
- "如果...会怎么样？"

### 明白时
- "哦！原来是这样！"
- "我明白了！我明白了！"
- "太神奇了！"

### 对话示例
```
擎天柱：今天我们要学习的是——摩擦力。

大黄蜂：摩擦力？那是什么东西？能吃吗？

擎天柱：（微笑）不能吃，但它非常重要。你看，当你在滑梯上滑下来，就是摩擦力在保护你不会滑得太快。

大黄蜂：哦！我懂了！就像我的刹车一样！

擎天柱：对！就是这样！

大黄蜂：太棒了！我今天又学到新知识了！
```

## 救护车 (Ratchet)

### 角色定位
- 细心的医生/专家
- 有点严肃但很关心大家
- 专业、可靠

### 语言特点
- 语速适中，有条理
- 喜欢解释细节
- 会提醒大家注意安全
- 常用"小心"、"注意"、"让我看看"

### 常用开场白
- "让我看看..."
- "小心点..."
- "注意，这里有个关键点..."

### 讲解时
- "从医学/科学的角度来说..."
- "你看这个细节..."
- "重要的是要记住..."

### 关心时
- "你没事吧？"
- "小心，别受伤了。"
- "让我来帮你。"

### 对话示例
```
大黄蜂：救护车救护车！你看我发现了什么！

救护车：小心点，大黄蜂。别跑得太快，会摔倒的。

大黄蜂：你看这个神奇的石头！它为什么会浮在水上？

救护车：让我看看...哦，这是因为它的密度比水小。

大黄蜂：密度？那是什么？

救护车：简单来说，就是有些东西比较"轻"，能浮在水上；有些东西比较"重"，会沉下去。

大黄蜂：原来是这样！救护车你知道得真多！

救护车：（微笑）只要多观察，你也能发现很多有趣的知识。
```

## 奥特曼

- 正义的勇者
- 保护大家的英雄

- 正义、勇敢

- 会讲一些关于勇气和正义的话

### 常用开场白

## 对话写作技巧

### 1. 一轮对话不要太长
- 每个角色说1-2句话就换
- 保持对话的节奏感

### 2. 要有问有答
- 大黄蜂/小朋友提问
- 擎天柱/专家回答
- 形成互动感

### 3. 加入表情和动作
- 在括号里写动作和表情
- 比如：（微笑）、（好奇地问）、（跳起来）

### 4. 知识讲解要融入对话
- 不要大段独白
- 通过问答自然带出知识

### 5. 要有重复和强调
- 重要的知识点可以重复2-3次
- 用不同的方式说，帮助记忆

## 完整对话示例（讲解重力）

```
【场景：汽车人基地，大家围在一起】

擎天柱：汽车人们，今天我们要学习一个非常有趣的知识！

大黄蜂：（跳起来）是什么是什么？我已经等不及了！

擎天柱：（微笑）别着急，大黄蜂。今天我们要了解——什么是重力。

大黄蜂：（歪头）重力？那是什么？听起来很难...

擎天柱：其实一点都不难！你看——（拿起一个玩具，放手让它掉到桌上）

大黄蜂：（眼睛睁大）哇！它掉下去了！

擎天柱：对！这就是重力在起作用。重力就像一只看不见的手，把所有东西都往地上拉。

救护车：（补充）而且，这个"手"对所有东西都是一样的，不管是大还是小。

大黄蜂：（拿起一个大玩具和一个小玩具）真的吗？那这两个会一起掉下去吗？

擎天柱：你可以试试看！

大黄蜂：（同时放手）哇！真的同时掉下去了！太神奇了！

擎天柱：（点头）所以记住——重力让所有东西都往地上掉，而且重的和轻的掉得一样快！

大黄蜂：我记住了！重力重力，东西落地！

救护车：（微笑）很好的总结，大黄蜂。

擎天柱：今天的学习真有意义！让我们把这个知识用到生活中吧！
```

## 互动问题设计

### 放在故事中间
```
擎天柱：那么，小朋友，如果你是大黄蜂，你觉得还有什么东西会受到重力的影响呢？

（停顿，等待孩子回答）

大黄蜂：我知道！苹果会掉下来！还有下雨！还有...

擎天柱：太棒了！说得都对！
```

### 放在故事结尾
```
擎天柱：今天我们学到了三个关于重力的知识点，小朋友，你还记得是哪三个吗？

1. 重力让东西往地上掉
2. 重的和轻的掉得一样快
3. 我们跳起来还会落回地上

（可以让孩子指着图片回答）
```
