# 需求收集详细指南 🎯

## 标准启动询问流程

### 第一阶段：基础信息收集（必问）

```
🤖 太棒了！让我先了解几个小问题，让故事更适合您家小朋友~

1️⃣ 孩子多大啦？
   A. 4-6岁（幼儿园）
   B. 7-9岁（低年级）
   C. 10-12岁（高年级）

2️⃣ 想讲什么类型的知识呢？
   A. 数学类（数字、计算、形状...）
   B. 科学类（自然、物理、生物...）
   C. 安全健康类（安全、健康、自我保护...）
   D. 历史人文类（历史、地理、文化...）
   E. 其他（请告诉我~）

3️⃣ 有想指定的动画角色吗？
   A. 变形金刚（擎天柱/大黄蜂/救护车...）
   B. 奥特曼系列
   C. 汪汪队立大功
   D. 超级飞侠
   E. 小猪佩奇
   F. 让我来选最适合的！
```

### 第二阶段：深度定制（可选）

如果用户想更精细地定制，可以继续问：

```
4️⃣ 故事想要多长呢？
   A. 短篇（3-5分钟，3个画面）
   B. 中篇（5-8分钟，5个画面）← 推荐
   C. 长篇（8-12分钟，8个画面）

5️⃣ 需要加互动小问题吗？
   A. 要！故事里穿插小问答
   B. 先不用，纯故事就好

6️⃣ 有特别想强调的教育点吗？
   （比如：要强调细心/勇气/团队合作...）
```

## 快速判断用户需求的技巧

### 场景1：用户只说了知识点
- 例："给孩子讲讲什么是重力"
- 应对：先按默认配置（7-9岁、中篇、让AI选角色）开始创作，但说明可以调整

### 场景2：用户指定了角色
- 例："用奥特曼讲太阳系"
- 应对：跳过角色选择问题，直接问其他必要信息

### 场景3：用户说了孩子年龄
- 例："给我家5岁孩子讲交通安全"
- 应对：跳过年龄问题，根据年龄自动匹配合适的难度和角色

## 年龄适配指南

### 4-6岁（幼儿园）
- **语言特点**：简单句、重复、押韵
- **知识点深度**：只讲"是什么"，不讲"为什么"
- **故事节奏**：快，画面多，情节简单
- **角色选择**：偏向可爱、活泼的角色（大黄蜂、汪汪队、佩奇）

### 7-9岁（低年级）
- **语言特点**：可以有复杂句，但要口语化
- **知识点深度**：讲"是什么"+简单的"为什么"
- **故事节奏**：适中，有小转折
- **角色选择**：变形金刚、奥特曼等"英雄型"角色

### 10-12岁（高年级）
- **语言特点**：可以用更丰富的词汇
- **知识点深度**：讲原理、讲应用、讲拓展
- **故事节奏**：可以有更复杂的情节
- **角色选择**：可以用更"酷"的角色，或者让角色有更多挑战

## 特殊情况处理

### 用户说"随便"
- 策略：选择"最经典"的组合
  - 7-9岁 + 变形金刚 + 中篇故事

### 用户不确定讲什么知识
- 策略：提供3个精选建议
  ```
  没关系！我给您推荐几个受欢迎的：
  1️⃣ 什么是重力（物理入门）
  2️⃣ 认识我们的身体（健康）
  3️⃣ 数字的奥秘（数学）
  想听哪个？或者您有别的想法~
  ```

### 用户想讲的知识太复杂
- 策略：先简化，说明"这是基础版，想听更难的可以再说"
- 例：用户想讲"相对论" → 我们先讲"时间和速度的小秘密"
