# 画面提示词库 🎨

## 核心原则

### 儿童友好三要素
1. **明亮鲜艳**：用暖色调、高饱和度
2. **无恐怖元素**：所有角色都是友好的表情
3. **画面简洁**：重点突出，不要太多杂乱细节

## 表情动作库

### 好奇发现
```
表情惊讶又好奇，眼睛睁得大大的，
手指着前方，好像发现了什么神奇的东西，
身体稍微前倾，充满探索的欲望，
儿童友好的可爱表情
```

### 认真学习
```
表情认真专注，眉头微微皱起但不是难过，
看着某个东西在思考，
手托着下巴或者拿着笔，
儿童友好的认真样子
```

### 开心庆祝
```
笑容灿烂，眼睛都笑弯了，
双手举起做庆祝动作，
跳起来或者挥舞手臂，
周围有彩纸或者星星特效，
儿童友好的快乐样子
```

### 担心关心
```
表情有点担心但不是害怕，
眉头轻轻皱着，看着需要帮助的对象，
伸出手准备去帮忙，
儿童友好的关心样子
```

### 恍然大悟
```
眼睛突然睁大，嘴巴变成"O"型，
好像突然明白了什么，
手指指着天空或者自己的脑袋，
儿童友好的顿悟表情
```

## 知识卡片设计

### 右下角卡片式（不挡主体）
```
（在画面描述完后补充）
画面右下角有一个可爱的圆角卡片，
卡片上有简单的文字和小图标，
卡片背景是柔和的渐变色，不遮挡主要画面，
卡片设计简洁可爱，儿童友好
```

### 卡片内容模板
- 数学类：3个关键点 + 1个小公式/图形
- 科学类：2个知识点 + 1个小示意图
- 安全类：3条安全规则 + 1个安全图标
- 文化类：2个文化要点 + 1个特色小物件

## 避坑指南

### ❌ 不要这样写
- "战斗场景"、"打败敌人" → 儿童友好，避免战斗
- "恐怖"、"黑暗"、"吓人" → 要用明亮温暖的
- "复杂的机械细节" → 简洁可爱就好
- "流血"、"受伤"（除非是温和的包扎演示）

### ✅ 要这样写
- "友好"、"温和"、"帮助"
- "明亮"、"鲜艳"、"温暖"
- "开心"、"好奇"、"探索"
- "学习"、"成长"、"团队合作"
